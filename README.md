# Ismail Budak - Portfolio Website

Personal portfolio website showcasing my projects, skills, and experience as a Full-Stack Developer & Data Analyst.

## 🚀 Features

- Modern, responsive design with dark theme
- Smooth animations and transitions
- Interactive 3D elements
- Project showcase with detailed descriptions
- Skills visualization
- Contact form integration

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **3D Graphics:** Three.js, React Three Fiber
- **Animations:** GSAP, Lenis
- **Icons:** Lucide React

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🎨 Customization

All personal information is stored in `src/data/resume.ts`. Update this file with your own details:

- Personal information (name, email, location, etc.)
- Education details
- Work experience
- Projects
- Skills
